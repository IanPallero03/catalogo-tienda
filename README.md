# 🛒 Catálogo de Tienda - Mini CMS

Aplicación web desarrollada con React que permite gestionar productos y categorías mediante un panel de administración.  
Pensada como una solución simple y adaptable para catálogos digitales o pequeños negocios.

---

## 🌐 Demo

👉 https://ianpallero03.github.io/catalogo-tienda/

---

## 🚀 Funcionalidades

- ✅ CRUD completo de productos (crear, editar, eliminar)
- ✅ Sistema de categorías dinámicas
- ✅ Asignación de categorías a productos
- ✅ Buscador en tiempo real
- ✅ Ordenamiento por precio (asc/desc)
- ✅ Paginación de productos
- ✅ Edición inline de productos
- ✅ Subida y previsualización de imágenes
- ✅ Panel de administración separado
- ✅ Personalización visual (diseño del catálogo)

---

## 🧠 Características técnicas

- Manejo de estado con React Hooks (`useState`)
- Arquitectura basada en componentes reutilizables
- Lógica de filtrado, ordenamiento y paginación combinada
- Persistencia de datos en `localStorage`
- Manejo de imágenes en formato base64

---

## 🛠️ Tecnologías utilizadas

- React (Vite)
- JavaScript (ES6+)
- Tailwind CSS

---

## ⚠️ Limitaciones actuales

- Los datos se almacenan en `localStorage` (no se sincronizan entre dispositivos)
- No cuenta con autenticación real
- Las imágenes se almacenan en base64 (no optimizado para producción)
